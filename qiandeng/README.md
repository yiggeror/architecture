# 千灯渡

千灯渡是一座可以自由飞行的江南幻想水城。雨夜从锦鲤灯舫和三孔水关开场。桥后有天瀑、金阙和高低错开的沿江街市，河道向山间盘曲。西南端敞向云水，西岸的小院里有琴榭、梅树和月洞门。

## 打开作品

[index.html](index.html) 是完整的单文件作品，已包含全部建模程序、渲染库、着色器和加载画面。云端工作区用 Chromium 通过本地 HTTP 入口观看。下载源码包后，在解压目录运行以下命令。

```sh
python -m http.server 4173
```

本机用支持 WebGL 2 的浏览器访问 `http://localhost:4173/`。同一局域网的手机可以使用电脑的局域网地址和端口 4173。观看时可断开外网。单独下载的 HTML 也可以放到静态服务器上直接观看。

## 人物图录

人物图录是独立的角色展示页，可直接打开 [studio.html](studio.html)。第一页的沈青蘅是丝市里的绸庄掌事，图录中的另三位主角是画舫琵琶师叶素弦、校书人许砚清和鼓手吴照。共可翻看十二位有名有姓的居民。选「到城中寻访」可在他们做事的地方继续自由浏览。分别下载两份网页时，把 `千灯渡.html` 与 `千灯渡-人物图录.html` 放在同一目录，即可从图录进入灯城。

拖动可以绕人物一周，滚轮或双指缩放可以看清脸、手和衣纹。暂停后拖动时间条，可在同一姿势对照天光和灯下，也能逐个检查手指、衣袖与道具的位置。「造型试样」可打开面部灰模，换衣款、梳式和纹样，调下颌，并把眼前的造型与职业动作导出成自包含的 GLB。

四套主角模型的骨架各有 22 个关节，导出包里有职业动作和独立眨眼。琴师的琴、商人的纸伞、校书人的折扇和鼓手的双槌会随人物一起导出。四个 GLB 在浏览器重新载入后分别播放了动作，也在 Godot 和 Blender 中核对了骨架、形变与贴图。

## 浏览

手机用右手滑动场景转头，左侧摇杆沿视线进退。抬头前推即可升空，俯视前推即可下降，左右推可横移，松手悬停。低处满推为每秒 10 米，半推约为每秒 3 米。满推巡航随高度加快，高空最高每秒 108 米。

桌面拖动环顾，W、S 和滚轮沿视线进退，A、D 横移。方向键转向，E、Q 升降，Shift 加速。昼夜切换保留当前的位置和朝向。

| 景点 | 取景 |
| --- | --- |
| 灯河 | 船队、水关、两岸亮窗和后方重叠的城阙 |
| 水关 | 从水面低处看三座石券、桥面飞廊和巡游灯船 |
| 灯市 | 锦浦的水边街巷，门廊内有丝市和木梯 |
| 云阙 | 西山双阙的金门、连廊和飞檐 |
| 全城 | 根据屏幕比例从空中看南栈、群城和最高处的星渡 |

从任一景点出发都可以接着飞行。

## 场景与检查

原有水院、码头和上游街市之外，外城有 14 个街坊、66 层台地和 583 座街屋。三座宫台、21 处街后塔楼、跨河桥和水闸连接各层街景。上河有七艘巡游船，下游另有四艘商船。建筑、人物、木船、雨云、窗绘和材质均由代码生成。三片水面的反射来自场景中的几何、天光和运动物体。

源码从 [src/main.js](src/main.js) 进入。重建需要 Node.js。

```sh
npm ci
npm test
npm run build
```

几何和运动测试使用实际场景网格，检查相邻檐口、跨巷桥楼、门洞、楼梯、山台、行人路线和船道。浏览器检查支持桌面、320×568 和 390×844 三种视口，包含双指转向飞行、昼夜切换、全城取景、碰撞与归航。安装 Python Playwright、Pillow 及 Chromium 后可以复验。

```sh
python test/viewer.py --url http://localhost:4173/
python test/viewer.py --url ./index.html --device 390 --checks opening layout two_fingers
python test/character_studio.py --url http://localhost:4173/studio.html
```

纯软件 WebGL 的首次建城和快速转向较慢。画面按显示尺寸设定稳定的绘制分辨率，飞行过程中沿用同一精度。硬件加速下，屋瓦、窗格、行人和倒影按设备支持选用最多 4× 多重采样。软件渲染在停驻时缓存多重采样的建筑，飞行时使用全分辨率边缘滤波。触控流程在 Chromium 的手机模拟视口中验证。

在 390×731 的 Chromium / SwiftShader 上，两版固定相同相机、绘制尺寸和采样时刻，每次等待 GPU 完成。六帧的中位耗时如下。真实手机的帧率随 GPU 和屏幕尺寸而变。

| 水关机位 | 初版 | 此版 |
| --- | ---: | ---: |
| 驻足看船 | 148 毫秒 | 102 毫秒 |
| 贴水前行并转向 | 1,372 毫秒 | 1,007 毫秒 |
| 离水 15 米横移 | 1,364 毫秒 | 1,153 毫秒 |

按同一机位的高采样参考检查 4× 路径，130,707 个高反差像素的平均 RGB 误差由 14.28 降至 8.84（以 255 为满量程）。[浑仪、灯绳、船影和水关倒影的放大对照](renders/20-边缘采样对照.jpg)
