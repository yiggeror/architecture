# 千灯渡

一座建在云峡上的江南灯市。镜头从河心开场，锦鲤灯舫驶向三孔水关，拱洞后方能看见北阙的三叠天瀑。两岸分布四片街区，西南角有一座带月洞门、梅树和琴榭的小院。最上层的金针高出河面 84 米。

## 打开作品

直接用支持 WebGL 2 的浏览器打开 [index.html](index.html)。单文件内含运行库、着色器和全部建模程序，可以离线使用。云工作区已通过本地 HTTP 服务打开作品。如果浏览器限制本地 HTML，或手机文件管理器只显示源码，可在电脑上进入解压后的目录并运行以下命令。

```sh
python -m http.server 4173
```

同一台电脑打开 `http://localhost:4173/`，同一局域网的手机可用电脑的局域网地址和端口 4173 访问。构建源码需要 Node.js，直接观看作品无需安装依赖。

## 浏览

手机用右手滑动画面转向，左侧摇杆沿当前视线进退。仰头前推可升空，低头前推可俯冲，左右推可横移，松手即可悬停。可以同时使用两根手指。

桌面拖动环顾，滚轮或 W、S 沿视线进退，A、D 横移。方向键转向，E、Q 也可升降，Shift 加速。时段按钮保留当前相机位置和朝向。

| 景点 | 可以看到的地方 |
| --- | --- |
| 灯河 | 锦鲤灯舫、沿岸店铺、桥洞和北阙金冠的共同视角 |
| 水关 | 三道石券、鼓楼、桥面飞廊，以及两岸的登桥石阶 |
| 灯市 | 西岸绸庄、茶肆和可进店登楼的千灯会馆 |
| 云阙 | 璇玑浑仪、内旋梯、东西高廊和水钟楼 |
| 全城 | 整座云岛的岸线、街区、远峰和南端瀑口 |

选取任一景点后都可继续自由飞行。

## 实景

[renders](renders) 中的雨夜与白昼主图共享机位 [6.25, 4.95, 47.00] 和第 0 秒的巡游位置。灯舫近照、全景、池庭及竖屏图也取自实际浏览器。短片记录了船队行进和锦鲤灯舫过券时的实时场景。

建筑、船舫、人物、草木、山体与天灯由源码构建，窗绘、灯绢、石木纹理和云层由程序绘制。两张 WebP 是本作真实首帧的加载封面，进入三维画面后即移除显示。场景里的水面使用当时的几何、动态物体和天空进行平面反射。

## 重建与检查

```sh
npm ci
npm run build
npm test
```

`src/main.js` 组合场景。`src/lighting.js` 负责材质与昼夜光场，`src/river.js` 负责河道及小院池面的反射，`src/walk.js` 负责视线飞行。

几何测试直接使用作品网格，覆盖相邻建筑檐缘交叉、街屋入口、全程登梯、两岸与高台衔接、七艘船的航线和船桨净空，以及移动船体和浑仪的相机碰撞。另附 [浏览器交互检查](test/viewer.py)。在装有 Chromium 和 Python Playwright 的环境中，用 `python test/viewer.py --help` 查看入口和视口参数。

已在桌面 Chromium 与 320×568、390×844 两种触摸视口实测。低性能设备会降绘制分辨率，并按投影大小简化远景；纯软件渲染时快速移机较慢。手机交互验证使用浏览器触摸模拟，帧率取决于设备的图形芯片。

本次交付通过 32 项网格与运动回归。沿七艘船的完整路线计算，船体与放灯竹排的最小净距为 1.69 米，计入桨尖仍留 1.05 米。触摸模拟从海拔 5.20 米飞至 95 米以上后返回，两种竖屏的落点误差都在 0.5 米以内。
